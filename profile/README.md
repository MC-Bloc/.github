## Active Projects

### SunBlock  
[SunBlock](https://minecraftbloc.milieux.ca/sunblock/) is a solar-powered minecraft server housed at the Milieux institute. 

Currently we are on the first iteration: SunBlock One. 

To view the server status, visit the [SunBlock One status website](https://sunblockone.milieux.ca). 

To build a SunBlock server, checkout our server [build guide](https://github.com/MC-Bloc/SunBlock/blob/main/BuildGuide.md) and [documentation here](https://github.com/MC-Bloc/SunBlock/blob/main/README.md).

The SunBlockCore mod can be [found here](https://github.com/MC-Bloc/SunblockCore-GL/). This mod is required on server and client side to communicate solar data. 

**If you are a minecraft modder and would like to make mods for SunBlock, please [reach us here](https://minecraftbloc.milieux.ca/contact/). We want to hear from you!**

We will be running the Gaia's Riddle - A Surival Multiplayer Minecraft server from May 1st 2025 - 15th July 2025.
